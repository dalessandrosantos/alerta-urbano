# Alerta Urbano

Sistema web desenvolvido com Python e Django para registrar e acompanhar problemas urbanos, como buracos nas ruas, lixo irregular, iluminação pública danificada e outros.

## Sobre o projeto

O objetivo do sistema é permitir que usuários registrem ocorrências urbanas de forma simples, informando uma descrição, categoria, localização e uma foto do problema.

## Tecnologias

- Python
- Django
- Bootstrap 5
